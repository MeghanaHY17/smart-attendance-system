# Smart Attendance System

A face recognition based attendance system built with Python and Flask.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Create a folder named `faces` inside the `SmartAttendance` folder and add student face photos.
3. Run the app: `python app.py`

## Features
- Face recognition to mark attendance automatically
- Attendance stored in a database
- Simple web interface
